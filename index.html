🛡️ Technical Details & Architecture

StegnoVault is a 100% browser-side image steganography and cryptographic inscription engine. Data is encoded and decoded directly inside your device memory with zero server uploads or external network requests.

🔒 AES-256-GCM
FIPS-compliant authenticated encryption with a 96-bit random IV preventing plaintext recovery and tampering.
🔑 PBKDF2 Hardening
100,000 SHA-256 derivation rounds with random 128-bit salt neutralize GPU rainbow tables.
🧬 LSB Carrier Modulation
Injects 1, 2, or 3 bits per RGB color channel. Alpha is preserved for lossless PNG conformity.
🔬 CTF Forensic Shield
1-bit stealth modulation shifts pixel values by only ±1, blending seamlessly into camera sensor noise.
📦 Binary Protocol: Pixel offset 0 embeds a 32-byte header with magic bytes STGN, bit depth, payload length, and encryption tags.
