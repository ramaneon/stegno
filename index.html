How It Works
1
Upload Cover Image
Load any PNG or BMP — lossless formats required. JPEG destroys LSB data during compression, so it's not supported.
2
AES-256-GCM Encryption
Message is encrypted with AES-256-GCM via a PBKDF2-derived key (100 000 iterations, random salt + IV). Unbreakable without the password.
3
LSB Steganography
Encrypted bytes are split into 1–3-bit chunks and written into the least-significant bits of the RGB pixel channels — visually identical to the original.
4
Secure Extraction
Recipient uploads the image, enters the password. LSB bits are read back, bytes reassembled, AES-GCM decrypts — message revealed instantly.
